# Material Playground Demo

An interactive Blinn-Phong material comparison demo - five UV spheres with distinct surface presets,
each adjustable in real time through ImGui.

[中文文档](../../zh-CN/demos/material-playground.zh-CN.md)

![Material Playground](../../screenshots/MaterialPlayground.png)

---

## Overview

This demo places five spheres on a lit ground plane, each initialized with a different
Blinn-Phong material preset (matte, shiny, metallic, plastic, chrome). All material
parameters - albedo color, specular power, and ambient strength - can be tweaked live
via ImGui, making it easy to compare how each parameter affects the final shading.

The scene reuses the same multi-pass forward rendering pipeline as the Shadow Mapping demo:
depth pass from the light, forward shading with PCF shadows, and an optional debug visualization.

### Rendering Pipeline

```
SceneRenderer::Render(scene)
├── ShadowPass::Execute()          → 2048x2048 depth map (front face culling)
├── ForwardPass::Execute()         → Blinn-Phong shading + PCF shadow sampling
└── TexturePreviewPass::Execute()  → Final output or shadow map preview
```

### Lighting Model

**Blinn-Phong** with per-sphere parameters:

| Parameter | Uniform | Range | Effect |
|-----------|---------|-------|--------|
| Albedo | `u_Albedo` | RGB color | Base surface color |
| Specular Power | `u_SpecularPower` | 1 – 512 | Highlight sharpness (higher = tighter) |
| Ambient Strength | `u_AmbientStrength` | 0.0 – 1.0 | Base illumination in shadow |

## Controls

| Input | Action |
|-------|--------|
| W / A / S / D | Move camera forward / left / backward / right |
| Q / E | Move camera down / up |
| Mouse | Look around (always active) |
| Scroll wheel | Adjust FOV |
| 1 | Show final color output |
| 2 | Show shadow map debug view |

### ImGui Controls

The **Material Playground** panel provides:

| Control | Description |
|---------|-------------|
| Output Mode | Toggle between final color and shadow map debug view |
| Light Direction | Adjust directional light direction (XYZ) |
| Light Color | Change light color |
| Light Intensity | Scale light brightness (0 – 5) |
| Per-sphere Albedo | Color picker for each sphere's base color |
| Per-sphere Specular Power | Drag slider for highlight sharpness (1 – 512) |
| Per-sphere Ambient | Drag slider for ambient strength (0 – 1) |

## Scene Setup

- **Ground plane**: 15x15 at Y=0, gray material (albedo 0.6, specular 16)
- **5 UV spheres**: radius 1.5, evenly spaced along the X axis at Y=1, generated by `MeshFactory::CreateSphere()` (16 stacks × 32 slices)
- **Directional light**: direction `(-0.5, -1.0, -0.3)`, white, intensity 1.2
- **Camera**: starts at `(0, 3, 10)` looking slightly downward

## File Structure

```
src/demos/MaterialPlayground/
├── MaterialPlayground.h           # Demo class declaration
└── MaterialPlayground.cpp         # Scene setup, material presets, ImGui panel, render dispatch

src/renderer/
├── SceneRenderer.h/cpp            # Multi-pass render orchestration
└── passes/
    ├── ShadowPass.h/cpp           # Depth-only pass from light POV
    ├── ForwardPass.h/cpp          # Forward shading with shadow sampling
    └── TexturePreviewPass.h/cpp   # Fullscreen texture visualization

assets/shaders/
├── ForwardLit.vert / .frag        # Blinn-Phong + PCF shadow sampling (u_Albedo, u_SpecularPower, u_AmbientStrength)
├── ShadowDepth.vert / .frag       # Depth-only shader
├── TexturePreview.vert / .frag    # Fullscreen quad visualization
└── *.spv                          # Compiled SPIR-V (generated at build time by glslang)
```

## Key Implementation Details

| Aspect | Detail |
|--------|--------|
| Sphere mesh | UV sphere, 16 stacks × 32 slices via `MeshFactory::CreateSphere()` |
| Albedo texture | 1x1 white pixel - color comes from `u_Albedo` uniform |
| Material sync | `SyncMaterialProperties()` pushes ImGui-edited values to `Material` every frame |
| Shadow mapping | Shared `SceneRenderer` pipeline - same PCF / bias / front-face culling as Shadow Mapping demo |
| Sphere layout | 5 spheres at X = {-5, -2.5, 0, 2.5, 5}, Y = 1, Z = 0 |
